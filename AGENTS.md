# Работа с сайтом

- Эта ветка — только сайт Vaska de Gamma и его статическая публикация.
- Не переносить изменения в main Комбайна и чужие проекты.
- Не менять порты, firewall, VPN, сертификаты, Nginx и Caddyfile ради оформления.
- Публикуемые файлы перечислены в manifest.json; обновлять их хеши вместе с контентом.
- Не добавлять личные контакты, адрес сервера, данные владельца и секреты.
- При обновлении менять только статику. Никогда не исполнять код из обновляемой ветки на VPS.
- В отчётах отличать сохранение в GitHub от подтверждённой публикации на VPS.
