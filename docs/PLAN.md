# Комбайн — где мы сейчас

## Идея
Главное правило: как у Amnezia — отсканировал QR, и работает. Юзер жмёт «Далее», выбора и инструкций по минимуму, всё, что можно, делает программа сама.
Простая программа для одного человека: купил VPS → запустил kombain-start.exe →
дальше всё в Telegram-боте. Безопасность и простота важнее функций.

## Путь юзера
0. **kombain-start.exe** (Windows): IP, логин, пароль сервера → сам ставит Комбайн и бота →
   «открой бота и отправь код 123456». Кто прислал код — тот хозяин.
1. **Бот → 🧠 Нейронки** → вступление «брат, ты офигеешь» → «Погнали собирать».
2. **🔐 Сейф — место сбора**, 3 пункта с галочками: домен, ключ Cloudflare, имя телефона.
   У каждого «как добыть» и «положить». Записи dns и *.dns в Cloudflare бот делает
   сам по ключу (занято другим адресом — спрашивает). Руками — только если ключ не пустил.
   Собранное переживает закрытие чата.
3. **🚀 Всё собрано — устанавливай** → жди 2–5 минут → настройки для телефона.

## Заметки для разработки
- Жёсткие требования к серверу — из-за Gemini: он самый капризный к IP.
  ChatGPT, Claude и остальные работают почти везде (у Васьки — даже на Германии).
  Проверенный под Gemini хостер — AdminVPS (Италия, Нидерланды, сеть HOSTKEY).
- Нейронки не нужны (только VPN) → подойдёт любой VPS, ограничений нет.
- Не раздувать вокруг Gemini: честный вопрос «что в нём хорошего, кроме цены» имеет смысл.
  Gemini — опция, а не центр продукта. Проверка IP должна показывать по каждой нейронке отдельно.

## Окна установщика (по одной мысли на окно, точки прогресса сверху)
1. Привет: «Это Комбайн — для ленивых. Ты тыкаешь, он делает.» + в домике: реклама/слежка режутся,
   провайдер не видит DNS, нейронки без VPN. Пароль не сохраняю, на компе ничего не меняю.
2. Какая нейронка: карточки Gemini (встроен в Android, YouTube, дешевле, капризный) / ChatGPT-Claude
   (умнее, любой сервер, дороже) / «всё равно».
3. Сервер: совет зависит от выбора (Gemini → AdminVPS, иначе любой). Есть / где купить.
4. Бот: @BotFather → /newbot → токен.
5. Соглашение: 3 строки + галка.
Дальше: вход на сервер → токен → установка → код. Домен и программы для телефона — потом, в боте.
Тексты нейтральные: без «брат» и без мужского/женского рода.

## Telegram-прокси — текст для юзера (модуль ещё не собран)
Два прокси: MTProxy и WEB-прокси (обкатаны на стенде, репа telegram-proxy).
Работает: сообщения, фото, видео, кружки, голосовые.
НЕ работает: звонки и видеозвонки. Простыми словами: звонок в Telegram идёт отдельной дорогой,
мимо прокси, напрямую к серверам звонков — их режут. Для звонков нужен VPN (VLESS), не прокси.
Подключение — одна ссылка: нажал, Telegram сам подключился.

## Госуслуги и свой DNS
- Факт (Васька): Сбербанк на телефоне через свой AdGuard открывается без проблем, Госуслуги иногда капризничают.
- В соглашении/«Как подключить»: «Госуслуги могут не открываться — переключи Частный DNS на Автоматически, сделай дела, включи обратно».
- Допилить и проверить вживую: домены Госуслуг (и .ru/.рф/.su) резолвить через российский DNS
  (upstream-правило AdGuard [/gosuslugi.ru/]... ). Сначала точечно Госуслуги, не весь .ru.

## Telegram-прокси в установщике (v0.2.0)
После входа на сервер exe спрашивает «Telegram открывается?».
Нет → ставит MTProxy (Fake TLS, порт 9443, без домена) → QR для телефона, кнопка «Открыть в Telegram» для компа, ссылка.
Дальше токен бота, как раньше. Тот же модуль в меню терминала: пункт 6. Кнопка в боте — следующим шагом.

## Версия
Номер в файле `VERSION`. Бот пишет его в /start и «Помощи», установщик — в заголовке окна и в шапке.
Поменял что-то для людей — поднимаешь номер в `VERSION` и выпускаешь релиз с тегом `v<номер>`.
