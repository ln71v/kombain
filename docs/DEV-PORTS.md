# Порты Комбайна (для разработки)

Один план на все модули, чтобы они не конфликтовали. Новый модуль берёт порт только отсюда.

## Снаружи
- 22/tcp — SSH, не трогаем
- 443/tcp — nginx stream, единый вход. Раздаёт по SNI (ssl_preread), карта в /opt/kombain/aiproxy/nginx/sni.d/*.map
- 443/udp — AmneziaWG
- 53/tcp+udp — AdGuard, обычный DNS (пускает только ClientID из списка)
- 853/tcp — AdGuard DoT, 853/udp — AdGuard DoQ

## Внутри (127.0.0.1, только через nginx)
- 3000 — AdGuard, служебный HTTP (API установки)
- 8443 — AdGuard HTTPS: DoH и админка (SNI .dns.<домен>)
- 8444 — Xray VLESS Reality (SNI: свой домен или маска)
- 8445 — Telegram-прокси
- 8080 — сайт-заглушка

## Проверено
- AdGuard с TLS не трогает 443/udp: HTTP/3 (serve_http3) по умолчанию выключен — с AWG на 443/udp не пересекается.
- nginx слушает только 443/tcp, своего 80 нет (конфиг заменяем целиком).
- Сертификат через DNS-01 (Cloudflare), порт 80 не нужен.

## Правила
- nginx — база: ставится первым при установке любого модуля, который живёт за 443.
  Сейчас nginx ставит модуль нейронок — вынести в отдельную базу при сборке модуля VLESS.
- Маска VLESS Reality и SNI Telegram-прокси не должны попадать в data/ai-domains.txt
  (например .microsoft.com там есть) — иначе nginx отправит трафик в настоящий сервис. Проверять при установке.
- Каждый модуль кладёт свою строку в sni.d/NN-имя.map и делает nginx -t перед reload.
- Файрвол (по желанию в конце): открыты только порты из раздела «Снаружи».
- DNS AdGuard ставится сам: апстримы DoH Cloudflare/Google/Quad9 (parallel), bootstrap 1.1.1.1/8.8.8.8/9.9.9.9, кэш 16 МБ + оптимистичный, DNSSEC, ratelimit 100, ECS выкл, IPv6-ответы выкл. Журнал 24 ч, статистика 7 дней.
