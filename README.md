# Комбайн

Установщик-меню для голого VPS. Задача — чтобы из России работали нейронки (ChatGPT, Gemini, Claude, Copilot) и было чем обходить блокировки. Без знаний Linux: где нужно сделать что-то руками, скрипт останавливается и говорит, куда нажать.

## Запуск

Зайди на сервер по SSH под root и вставь одну строку:

```
bash <(curl -Ls https://raw.githubusercontent.com/ln71v/kombain/main/kombain.sh)
```

Дальше меню открывается командой `kombain`.

## Что нужно

- VPS за границей (Европа, США), Ubuntu 22.04 или 24.04, от 1 ГБ памяти.
- Для прокси нейронок: любой домен и бесплатный аккаунт Cloudflare. Как купить и настроить — скрипт расскажет по шагам.

## Где взять сервер

Подойдёт любой рабочий хостер за границей. Нейронки пускают не всех: адреса некоторых хостеров у них в бане. Здесь только то, что проверено вживую.

**Проверено, нейронки работают** (список пополняется по мере проверки):
- **AdminVPS** ([adminvps.ru](https://adminvps.ru)) — Италия и Нидерланды. Оплата из РФ.
  Сеть: **AS57043 HOSTKEY B.V.**, организация на адресах — Snowd Security OU.
  Обе страны сидят в одной сети. Если нужен запасной сервер, второй бери с другой сетью: забанят сеть — лягут оба.

**Как узнать сеть своего сервера** (на сервере, одной командой):
```
curl -s ipinfo.io/org
```
Покажет номер сети (AS…) и владельца. Запасной сервер должен быть с другим номером.

Купил сервер — сразу проверь адрес, пока не поздно отказаться:
```
bash <(curl -Ls IP.Check.Place) -l en
```
Смотри блок 5: у ChatGPT должно быть `Yes` и `Native`.

## Где взять домен

Подойдёт любой регистратор, лишь бы Cloudflare принял домен.

**Проверено:**
- **REG.RU** ([reg.ru](https://www.reg.ru)) — покупка быстрая, Cloudflare принимает.

Купил домен — сразу закажи **«Скрытие персональных данных»** (домен → «Управление» → «Ещё услуги»). Без этого твои телефон и почта видны любому в Whois.

## Что умеет

| Пункт | Что делает | Готовность |
|---|---|---|
| Бот | пульт в Telegram: ставишь бота — дальше всё ставишь и настраиваешь из Telegram | готово |
| Прокси для нейронок | AdGuard Home + nginx. Нейронки открываются без VPN, просто через DNS | готово |
| VLESS Reality + сайт-заглушка | VPN, который для провайдера выглядит как обычный сайт | скоро |
| AmneziaWG | быстрый VPN с маскировкой | скоро |
| WARP | выпуск трафика VPN через Cloudflare | скоро |
| Telegram-прокси | MTProxy и WEB-прокси для Telegram | скоро |

## Бот

Пункт 1 в меню. Понадобится токен от @BotFather и твой ID от @userinfobot — скрипт подскажет, где их взять.
После этого открываешь бота и ставишь всё кнопками. Бот слушается только тебя.

Установка в боте в два этапа:
1. **Сбор в «Сейф»** — по пунктам: домен, записи в Cloudflare, API-ключ, имя телефона. У каждого пункта — подсказка, где взять. Собранное сохраняется: закрыл чат, вернулся завтра — всё на месте.
2. **Одна кнопка «Устанавливай»** — и ждёшь пару минут.

## Прокси для нейронок — как это работает

1. На телефоне в «Частный DNS» вписываешь адрес своего сервера.
2. Когда телефон ищет `chatgpt.com`, твой AdGuard отвечает: «он здесь, на сервере».
3. nginx на сервере пересылает подключение в настоящий ChatGPT. ChatGPT видит заграничный IP.
4. Остальные сайты идут как обычно, напрямую. Скорость не страдает.

DNS шифрованный (DoH/DoT), провайдер ответы не подменит. Доступ только у устройств, которые ты добавил по имени. Файрвол закрывает всё, кроме нужных портов.

Список доменов нейронок — в `data/ai-domains.txt`. Добавил строку — в меню «Обновить список нейронок».

## Где что лежит на сервере

- `/opt/kombain/src` — сам Комбайн
- `/opt/kombain/aiproxy` — настройки, сертификат, пароль админки (`env`)
- `/opt/kombain/backup` — копии системных файлов, которые Комбайн менял

## Обновить

```
kombain --update
```
