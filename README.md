# Комбайн

Установщик-меню для голого VPS. Задача — чтобы из России работали нейронки (ChatGPT, Gemini, Claude, Copilot) и было чем обходить блокировки. Без знаний Linux: где нужно сделать что-то руками, скрипт останавливается и говорит, куда нажать.

## Запуск

**Проще всего (Windows):** скачай `kombain-start.exe` из [Releases](https://github.com/ln71v/kombain/releases), запусти, впиши IP, логин и пароль от сервера. Он сам всё поставит и скажет, что отправить боту.
Windows может написать «Защитник Windows предотвратил запуск» — нажми «Подробнее» → «Выполнить в любом случае». Программа без платной подписи. Её собирает сам GitHub из кода в папке `starter` — рядом лежит контрольная сумма `.sha256`, по ней можно проверить, что файл не подменили.

**Или вручную:**

Зайди на сервер по SSH под root и вставь одну строку:

```
bash <(curl -Ls https://raw.githubusercontent.com/ln71v/kombain/main/kombain.sh)
```

Дальше меню открывается командой `kombain`.

## Что нужно

- VPS за границей (Европа, США), Ubuntu 22.04 или 24.04, от 1 ГБ памяти.
- Для прокси нейронок: любой домен и бесплатный аккаунт Cloudflare. Как купить и настроить — скрипт расскажет по шагам.

## Где взять сервер

Подойдёт любой рабочий хостер за границей. Нейронки пускают не всех: адреса некоторых хостеров у них в бане. Здесь только то, что проверено вживую.

**Проверено, нейронки работают — все, включая Gemini** (список пополняется по мере проверки):
- **AdminVPS** ([adminvps.ru](https://adminvps.ru)) — Италия и Нидерланды. Оплата из РФ.
  Сеть: **AS57043 HOSTKEY B.V.**, организация на адресах — Snowd Security OU.
  Обе страны сидят в одной сети. Если нужен запасной сервер, второй бери с другой сетью: забанят сеть — лягут оба.
- **Fornex** ([fornex.com](https://fornex.com)) — Нидерланды, Роттердам. Своя сеть **AS16003** Fornex Hosting S.L. Оплата МИР и СБП, минимум на месяц.
  Google видит адрес испанским (страна фирмы) — Gemini это не мешает. IP не меняют: попался плохой — только возврат денег.
  Проверено 08.11.2026.

**Проверено, Gemini не работает** (ChatGPT, Claude, VPN, Telegram — работают):
- **HIP-Hosting** ([hip.hosting](https://hip.hosting)) — много стран, дёшево. Сеть **AS41745**: Google видит все её адреса российскими,
  поэтому Gemini не пускает ни в одной стране. Проверено 09.10 и 08.11.2026.

**Не проверено:**
- **CloudVPS** ([cloudvps.by](https://cloudvps.by)) — оплата из РФ. Номер сети не называют — проверяй после покупки.

**Проверено, не бери:**
- **Eurobyte** ([eurobyte.ru](https://eurobyte.ru)) — Амстердам, сеть **AS216139** Iron Hosting Centre.
  ChatGPT и Claude работают, но **Gemini не пускает** (геоблок). У части домашних провайдеров в РФ адрес глушат:
  страница начинает грузиться и замирает. Проверено 08.10.2026.

**Купил — сначала проверь, открывается ли IP из России.** Прямо в Комбайне (exe и Android): экран «Где взять сервер» → вставь IP → «Проверить».
Зелёное — ставь. Красное — пиши хостеру «смените IP на не заблокированный в РФ, из другой подсети» или проси возврат, пока не вышел срок.
На время проверки выключи VPN на компе или телефоне, иначе проверка соврёт.

**Как узнать сеть своего сервера** (на сервере, одной командой):
```
curl -s ipinfo.io/org
```
Покажет номер сети (AS…) и владельца. Запасной сервер должен быть с другим номером.

Сервер куплен — сразу проверь адрес, пока не поздно отказаться:
```
bash <(curl -Ls IP.Check.Place) -l en
```
Смотри блок 5: у ChatGPT должно быть `Yes` и `Native`.

## Где взять домен

Подойдёт любой регистратор, лишь бы Cloudflare принял домен.

**Проверено:**
- **REG.RU** ([reg.ru](https://www.reg.ru)) — покупка быстрая, Cloudflare принимает.

Домен куплен — сразу закажи **«Скрытие персональных данных»** (домен → «Управление» → «Ещё услуги»). Без этого твои телефон и почта видны любому в Whois.

| Пункт | Что делает | Готовность |

## Бот

Пункт 1 в меню. Понадобится токен от @BotFather и твой ID от @userinfobot — скрипт подскажет, где их взять.
После этого открываешь бота и ставишь всё кнопками. Бот слушается только тебя.

Установка в боте в два этапа:
1. **Сбор в «Сейф»** — по пунктам: домен, ключ Cloudflare, название телефона. Записи в Cloudflare бот делает сам по ключу. У каждого пункта — подсказка, где взять. Собранное сохраняется: закрыл чат, вернулся завтра — всё на месте.
2. **Одна кнопка «Устанавливай»** — и ждёшь пару минут.

## Прокси для нейронок — как это работает

1. На телефоне в «Частный DNS» вписываешь адрес своего сервера.
2. Когда телефон ищет `chatgpt.com`, твой AdGuard отвечает: «он здесь, на сервере».
3. nginx на сервере пересылает подключение в настоящий ChatGPT. ChatGPT видит заграничный IP.
4. Остальные сайты идут как обычно, напрямую. Скорость не страдает.

DNS шифрованный (DoH/DoT), провайдер ответы не подменит. Файрвол закрывает всё, кроме нужных портов.

**Ограничение — знай про него.** Список устройств защищает только DNS: чужой не получит от твоего AdGuard подменённые адреса. Но сам вход на 443 (nginx) никого не проверяет — пропускает любого по имени сайта (SNI). Кто знает IP сервера, может ходить через него в нейронки из `data/ai-domains.txt`, минуя AdGuard: прописать адрес у себя в hosts или в своём DNS. В другие сайты не пустит — чужие имена nginx отбрасывает. Чем грозит: лишняя нагрузка на сервер и риск, что нейронки забанят его IP за чужие запросы. Закрыть это списком адресов нельзя — у телефонов IP всё время меняется.

Список доменов нейронок — в `data/ai-domains.txt`. Добавил строку — в меню «Обновить список нейронок».

## Где что лежит на сервере

- `/opt/kombain/src` — сам Комбайн
- `/opt/kombain/aiproxy` — настройки, сертификат, пароль админки (`env`)
- `/opt/kombain/backup` — копии системных файлов, которые Комбайн менял

## Обновить

```
kombain --update
```
